# Pickly 기능명세서 (Feature Specification)

> 본 문서는 현재까지 구현된 UI 시안(7개 화면: 로그인 / 홈 / 새 투표 만들기 / 공유 / 투표하기(스와이프) / 결과 / 마이페이지)을 근거로 작성된 제출용 기능 명세서입니다. 화면에 존재하지 않는 기능은 임의로 추가하지 않았으며, 확장 가능성이 있는 항목은 모두 **MVP 이후 / 향후 고도화** 섹션에 분리되어 있습니다.

- 서비스명: **Pickly**
- 한 줄 소개: 친구들의 반응과 AI 분석으로 베스트컷을 찾아주는 사진 선택 플랫폼
- 플랫폼: Mobile Web (Mobile First, max-width 420px 기준)
- 작성 기준 화면: `/`, `/home`, `/create`, `/share/$id`, `/vote/$id`, `/result/$id`, `/mypage`

---

## 1. 문제 정의

### 1-1. 사용자가 겪는 문제
| 구분 | 내용 |
| --- | --- |
| 선택 피로 | 한 장소에서 수십 장의 사진을 촬영하지만, 어떤 컷을 SNS·프로필·썸네일에 올릴지 결정하지 못함 |
| 주관 편향 | 본인 눈에는 모두 비슷해 보여 객관적 평가가 어려움 |
| 피드백 비효율 | 친구에게 카톡으로 사진을 일일이 보내며 "뭐가 나아?"를 묻는 과정이 번거롭고 응답률이 낮음 |
| 근거 부재 | 친구가 골라줘도 "왜 좋은지"에 대한 설명이 없어 다른 사진에도 활용하기 어려움 |

### 1-2. 기존 서비스의 한계
| 기존 방식 | 한계점 |
| --- | --- |
| 단톡방 사진 공유 | 응답이 산만하고 집계 불가, 반응이 휘발됨 |
| 인스타 스토리 투표 스티커 | 2지선다만 가능, 결과 데이터 빈약 |
| 일반 설문 도구 (구글 폼 등) | 사진 중심 UX가 아님, 모바일에서 투표 흐름이 무거움 |
| AI 사진 평가 단독 앱 | 인간(친구)의 감정·맥락 반응이 반영되지 않음 |

### 1-3. 본 서비스가 해결하는 가치
- **사람 ↔ 사람**: 친구들의 좌/우 스와이프 한 번으로 가벼운 참여 유도
- **정보 ↔ 정보**: 투표 집계 + AI Vision 분석을 결합한 "근거 있는 베스트컷"
- **공간 ↔ 공간**: EXIF 위치 기반으로 포토스팟 통계와 키워드를 누적 → 다른 사용자에게 추천

## 2. 타겟 유저

### 2-1. 핵심 타겟
- 20~30대 SNS 활동자 (인스타그램·스레드·블로그 업로드 빈도가 주 1회 이상)
- 프로필/썸네일 사진을 자주 교체하는 사용자

### 2-2. 서브 타겟
- 유튜브/숏폼 크리에이터 (썸네일 A/B)
- 1인 기업·소상공인 (홍보 이미지 선정)
- 사진 동호회·커플·여행 그룹

### 2-3. 페르소나

**페르소나 1 — 인스타 업로더 "지수" (24, 대학생)**
- 주말마다 친구와 카페·전시를 다님
- 한 번에 30~50장씩 촬영하지만 업로드는 3장으로 추려야 함
- Pain Point: "단톡방에 다 올리기엔 미안하고, 혼자 고르기엔 자신 없음"
- Pickly 사용 시나리오: 새 투표 만들기 → 카톡 링크 공유 → 결과 화면에서 베스트컷 다운로드

**페르소나 2 — 1인 크리에이터 "도현" (29, 유튜버)**
- 썸네일 후보 4~5개를 늘 고민
- Pain Point: 댓글로 묻기엔 채널 톤이 흐트러짐
- Pickly 사용 시나리오: 친한 동료 크리에이터들에게 링크 전달 → AI 분석으로 구도/표정 점검

**페르소나 3 — 투표 참여자 "민기" (27, 회사원)**
- 친구가 보낸 링크를 받음
- Pain Point: 설문은 귀찮음
- Pickly 사용 시나리오: 링크 → 스와이프 4번 → 10초 만에 완료

## 3. 서비스 개요

- **한 줄 소개**: 친구들의 반응으로 베스트컷을 찾아보세요!
- **Value Proposition**: "10초 스와이프로 모인 친구 반응 + AI 분석 = 근거 있는 베스트컷 1장"
- **서비스 구조 요약**
```
[사진 업로드자]                [투표 참여자]                [AI]
 사진 N장 업로드     →  링크   스와이프 좋음/별로  →  집계  Vision 분석
        ↓                                                      ↓
   투표 생성/공유                                       구도·표정·조명 코멘트
        ↓
   결과 화면(랭킹 + AI 인사이트 + 포토스팟 키워드)
```

## 5. 화면 흐름 (User Flow)

### 5-1. 전체 사이트맵
```
/ (로그인)
 ├─ /home (홈)
 │   ├─ /create (새 투표 만들기)
 │   │   └─ /share/$id (공유 화면)
 │   │        ├─ /vote/$id (친구 화면 미리보기)
 │   │        └─ /result/$id (내 결과)
 │   ├─ /result/$id (내 투표 카드 클릭)
 │   └─ /mypage (마이페이지)
 └─ /vote/$id (외부 링크로 참여자가 진입)
```

### 5-2. 생성자(Creator) Flow
```
로그인  →  홈  →  새 투표 만들기  →  공유 화면
                                       ├─ 링크 복사 / 카톡 공유
                                       └─ (대기) → 결과 화면
```

### 5-3. 참여자(Voter) Flow
```
카톡 링크 클릭  →  /vote/$id (스와이프)  →  투표 완료 카드  →  홈(둘러보기)
```

## 6. 주요 사용자 시나리오

### 시나리오 1 — 신규 사용자의 첫 사용 (생성자)
1. 로그인 화면 진입 → Kakao 로그인
2. 홈에서 통계와 인기 포토스팟 확인
3. "새 투표 만들기" 클릭 → 사진 4장 업로드

### 시나리오 2 — 핵심 기능 사용 (참여자)
1. 카톡으로 받은 링크 클릭 → `/vote/demo`

4. 🎉 완료 카드 확인 후 "닫기" → 홈

### 시나리오 3 — 재방문 사용자 행동 (결과 확인)
1. 홈 진입 → "내 진행중인 투표" 아코디언 펼침
2. 종료된 투표 카드 클릭 → 결과 화면

4. 1위 사진의 구도/표정/조명 코멘트 확인
5. "결과 이미지 저장"으로 다운로드

## 8. MVP 범위

### 8-1. MVP (현재 UI 시안 기준)
- 소셜 로그인 / 둘러보기
- 홈 대시보드 (통계 카드, 인기 포토스팟 캐러셀, 내 투표 아코디언)
- 새 투표 만들기 (제목·사진 2~10장·위치 토글·마감일 3종)
- 위치 자동 그룹화 (EXIF 기반)
- 공유 화면 (URL 복사·카카오 공유·미리보기)
- 스와이프 투표 (드래그·버튼·되돌리기·진행률·완료 카드)
- 결과 (헤더·AI 인사이트·랭킹·TOP3 분석·결과 저장)
- 마이페이지 (프로필·3-Stat·투표 리스트·회원 탈퇴)

### 8-2. MVP 이후
- 카카오/Apple 실제 SDK 연동
- 결과 이미지 서버 사이드 렌더링(공유 OG 이미지)
- 투표 알림(마감 임박/결과 도착) 푸시
- 익명 vs 실명 참여자 선택 옵션
- 댓글/이모지 반응 추가

### 8-3. 향후 고도화
- AI 기반 자동 후보 컷 추천(업로드 사진 N장 → AI가 베스트 3 사전 추출)
- 포토스팟 지도 뷰 + 검색
- 크리에이터/브랜드용 A/B 분석 대시보드
- 다국어(EN/JP)
- 결제 기반 Pro 플랜 (Vision 분석 무제한, 워터마크 제거)

## 10. 심사위원용 1-Page 요약

> **Pickly — 친구들의 반응으로 베스트컷을 찾아보세요!**

**문제.** 사람들은 매번 수십 장의 사진 중 어떤 컷을 SNS·프로필·썸네일에 올릴지 고민합니다. 단톡방에 묻기는 미안하고, 혼자 고르기엔 자신이 없으며, 골랐다 해도 "왜 좋은지"에 대한 근거가 없습니다.

**해결.** Pickly는 **사진 → 친구의 10초 스와이프 → AI Vision 분석**을 하나의 흐름으로 묶은 사진 선택 플랫폼입니다. 생성자는 사진을 올리고 카톡 링크를 공유하면, 친구들은 좌/우 스와이프 한 번이면 참여가 끝납니다. 결과 화면에서는 **추천율 랭킹 + AI 요약 + 공간 키워드 + TOP3 구도/표정/조명 분석**까지 한 번에 받습니다.

**Mesh 연결.**
- 사람↔사람: 친구들의 라이브 투표
- 정보↔정보: 추천율 집계 + GPT-4o Vision 분석
- 공간↔공간: EXIF 기반 포토스팟 통계와 #감성/#노을 같은 공간 키워드

**핵심 화면(7).** 로그인 / 홈 / 새 투표 만들기 / 공유 / 스와이프 투표 / 결과 / 마이페이지

**MVP 강점.**
1. **참여 마찰 최소화** — 스와이프 1회 = 1표, 진행률·되돌리기·완료 카드까지 한 화면 완결
2. **근거 있는 결과** — 단순 1위가 아니라 "왜 이 사진이 좋았는가"를 AI가 텍스트와 태그로 설명
3. **누적될수록 강해지는 데이터** — 위치 기반 포토스팟 랭킹은 사용자가 늘수록 가치가 증가

**타겟.** 20~30대 SNS 업로더, 1인 크리에이터, 소상공인

**확장.** 푸시 알림, 익명 참여, AI 사전 추출, 포토스팟 지도, Pro 결제 플랜

**디자인.** 다크 + 네온 그라데이션, Instagram·Linear·Notion의 감성을 결합한 모바일 퍼스트 UI.
